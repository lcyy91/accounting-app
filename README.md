# 💰 轻松记账 - 个人财务管理应用

## 📌 项目简介

轻松记账是一款基于 Web 的个人记账应用，帮助用户方便地记录和管理日常收支。无需安装任何软件或注册账号，打开浏览器即可使用。

## ✨ 功能特色

| 功能 | 说明 |
|------|------|
| 📊 **仪表盘** | 实时展示本月收入、支出、结余 |
| 📝 **记账管理** | 添加、编辑、删除收支记录 |
| 🏷 **分类管理** | 9 种支出分类 + 5 种收入分类，带 emoji 图标 |
| 📅 **月度筛选** | 按月份浏览历史记录 |
| 🔍 **类型过滤** | 按全部/支出/收入筛选 |
| 📈 **数据可视化** | 支出分类饼图 + 近6月收支趋势柱状图 |
| 💾 **本地存储** | 数据保存在浏览器 localStorage，刷新不丢失 |
| 📥 **数据导入导出** | 支持 JSON 格式导出备份和导入恢复 |
| 📱 **响应式设计** | 适配手机、平板、桌面端 |

## 🚀 运行方式

### 方法一：直接打开（推荐）

1. 双击 `index.html` 文件，自动在浏览器中打开
2. 开始记账！

### 方法二：本地服务器（可选）

如果你有 Node.js 环境，可以用任意静态服务器：

```bash
# 使用 Node.js
npx serve accounting-app

# 或使用 Python
python -m http.server 8080
```

然后访问 `http://localhost:8080`

## 🛠 技术栈

- **HTML5 + CSS3**：页面结构与样式
- **JavaScript (ES6+)**：核心业务逻辑
- **Chart.js 4.4.7**：图表可视化（CDN 引入）
- **localStorage**：数据持久化

## 📖 使用说明

1. **记一笔**：点击「+ 记一笔」按钮，选择支出/收入，填写金额、分类、日期等信息
2. **查看记录**：左侧列表显示当月所有记录，可通过顶部筛选按钮过滤
3. **编辑记录**：鼠标悬停在记录上，点击 ✏️ 按钮编辑
4. **删除记录**：鼠标悬停在记录上，点击 🗑 按钮删除
5. **切换月份**：点击顶部 ◀ ▶ 按钮切换月份
6. **导出数据**：点击标题栏 📤 按钮下载数据备份
7. **导入数据**：点击标题栏 📥 按钮导入之前备份的数据

## ⚠️ 注意事项

- 数据存储在浏览器本地，清除浏览器数据会导致记录丢失
- 建议定期使用「导出」功能备份数据
- 更换浏览器或设备后，需要通过「导入」功能恢复数据
